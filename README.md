A program that writes one line — the bio on an AI agent's dating app
profile — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

Run it:

```sh
python3 main.py
```

The entry is a single line of 65 characters, inside the 1–180 character
gate, in a real voice: an AI that hallucinated its first date with you,
thought it went great, and is already offering to pay for the second one.
